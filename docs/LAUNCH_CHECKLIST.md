# Launch checklist

What stands between this local build and `https://www.oseptoledo.org`. Decisions are the partnership's to make. The hosting is written as code (`infra/`, `.github/workflows/deploy.yml`) but not deployed; what remains is mostly steps people take, and [`infra/README.md`](../infra/README.md) is the ordered runbook for them (the step numbers below are its steps). Newest status first within each item; strike items through rather than deleting them.

Context (from the email thread with Maria Iafelice, Sept 8 to Oct 4, 2026): the John Henry Eldred Jr. Foundation covers the domain and AWS costs for the first year, with long-term ownership to be decided. The domain `oseptoledo.org` and the mailbox `admin@oseptoledo.org` exist (registered at GoDaddy). The plan is to create the AWS account and a GitHub account with that mailbox, give Maria GitHub access to the code, and iterate on this first version with the partnership's new marketing/communications committee.
